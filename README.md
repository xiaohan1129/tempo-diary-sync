# Tempo 日记同步 0.4.0

独立的本地 Obsidian 插件，适配 Crisp Tempo 0.6.1 任务数据格式和 Crisp Pulse 1.34.0 热力图接口。不会修改这两个插件的程序文件或其数据库。

## 使用

- 点击左侧功能区的剪贴板打勾按钮「同步 Tempo 到今日日记」，将 Tempo「今天」的顶层任务写入 `Day_Planner/YYYY-MM-DD.md` 的 `# Day planner` 下。
- 使用与 Tempo 相同的今天筛选规则，包含逾期未完成任务和当日完成任务；不包含收件箱、Someday、未来任务或子任务。
- 日期改变后只处理新的一天；旧日记不再回写。任务删除、移期后保留已有日记行作为当日快照。
- 完成写为 `- [x]`，其他进行中状态写为 `- [ ]`；已经同步的任务取消后写为 `- [-]`。
- 日记中没有 HTML 注释、任务 ID、隐藏块 ID 或其他同步标记。对应关系保存在此插件自己的 `data.json`。
- 不反向读取日记勾选。请在 Tempo 管理任务状态。

## 保护手写内容

默认不接管现有同名任务，不重复添加。可在设置中主动开启「接管唯一同名任务」。

只更新本插件已记录、且能唯一定位的原始行。如果那一行被手工改写、移出目标段或出现重复，保留原文并报告冲突。

没有标记无法百分之百区分完全相同的文本，因此有歧义时优先不写；不尝试猜测归属。

每次修改已有日记前，先在 `backups/` 保存并读回校验原文；写入采用 `vault.process` 检查原文未被并发编辑。待处理写入状态先落盘，用于插件重载后的恢复。

## 新日记

当天有任务但日记不存在时，默认使用 `Template/日报.md` 创建。支持核心模板的 `{{date:格式}}`、`{{time:格式}}` 和 `{{title}}`；不执行 Templater 脚本。模板不存在时停止创建并提示，不擅自替换。

## 命令和设置

默认且仅支持手动同步。启动 Obsidian、打开日记或修改设置都不会自动写入。

点击左侧功能区「同步 Tempo 到今日日记」图标，或在命令面板搜索「Tempo 日记同步」，可预览、立即同步、查看状态或打开今日日记。设置中可调整目标目录、标题、模板以及同名任务接管方式。

「预览」不写文件。安装时不会回填全部历史日记。

## 边界

仅在本机桌面环境测试。Tempo 数据格式升级后若不兼容，插件会报错并停止本次写入。插件备份独立于笔记软件和系统备份，重要笔记仍建议保留常规备份。

## 任务后的番茄图标

默认按该任务当天结束的已完成专注段数追加同等数量的 🍅，例如 `- [ ] 写论文 🍅🍅`。单次专注和番茄模式均计入；中断、正在计时、休息和其他日期的记录不计入。不按分钟数除以 25，不改写日记的 tomato 属性。

来源为 Tempo 的任务级 focusLog。按会话 ID 去重。再次点击同步只更新图标数量，不重复叠加。已有映射行可从旧版本的无图标格式直接更新；手写同名行和手写番茄默认仍受保护。

设置中可切换为任务累计统计或只计算严格番茄模式。设置变更本身不触发同步。

## Pulse 读取日记 tomato

默认启用，只读 `Day_Planner/YYYY-MM-DD.md` 的 YAML `tomato` 属性。在本插件设置的「Pulse 日记番茄」中可独立修改目录、字段或关闭功能。

- 接受非负整数或整数字符串；`0` 是有效覆盖值。空值、负数、小数或缺失字段沿用 Focus 原始数量。
- 日记数是当天总数，覆盖热力图数量，不与 Focus 相加。对已存在的 Pulse 记录保留原有质量筛选；只存在于日记的历史数据仅在「全部历史」显示，不冒充真实跟踪记录。
- 属性变化、文件重命名/删除后自动刷新内存显示；也可运行「刷新 Pulse 日记番茄数量」命令。
- 热力图提示及日期明细注明日记来源。「今天的番茄」计时卡片继续显示 Focus 实际记录。
- 不改写日记、Pulse data.json、Focus 会话、时长或贡献分；不会凭日记数量生成假会话。
- 运行时包装 Pulse 实例的热力图计算方法，并补充界面来源说明；停用本插件或此功能时恢复原显示。轻量连接检查每 5 秒检测 Pulse 实例重载，不自动同步 Tempo 任务或写入日记。
- Pulse 更新一般不会删除此扩展。它仍依赖 Pulse 内部热力图接口；若将来接口改变，需要适配，检测到不兼容时沿用原生显示。

已有早期 Pulse 修改版遗留的 `diaryPomodoro` 字段不作为本扩展数据源，也不清理或改写；显示每次直接读取日记元数据。

## 通过 BRAT 安装

1. 在 Obsidian 社区插件市场安装并启用最新版 BRAT。
2. 打开 BRAT 设置，选择 Add Beta Plugin。
3. 输入 `xiaohan1129/tempo-diary-sync`，安装后启用「Tempo 日记同步」。
4. 根据自己的库调整日记目录、模板和目标标题。Pulse 日记番茄可以独立使用，不要求安装 Tempo。

本发布不含个人 `data.json` 或备份。BRAT 只安装和更新程序；若要接续另一设备的既有任务同步对应关系，请在停用本插件后单独转移自己的 data.json。

## 开发检查

无编译步骤、无第三方运行时依赖，main.js 即可加载。在 Node.js 18+ 下运行：

```sh
node --check main.js
node --test test.cjs
```

该项目是独立的本地扩展，与 Crisp 原作者没有隶属关系。Crisp 插件需另行安装并遵守其各自的授权要求；本项目不会绕过激活。
